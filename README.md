## ✨ Highlights

- 🎨 Slanted cut-corner cards and hazard-tape banners
- 🌌 Animated grid background with floating particles
- 🃏 3D card tilt, scroll-reveal and scrolling marquees
- ♿ All motion stops automatically with `prefers-reduced-motion`
- 📱 Responsive, no horizontal scroll on mobile

## 🚀 Deploy

Put `index.html` in the repository root, then enable **Settings → Pages** on the `main` branch.

## 🛠️ Customize

Colors, fonts and spacing are CSS variables at the top of `index.html`:

```css
:root{
  --c-yellow:#ffe600;
  --c-blue:#2f8bff;
  --font-main:'Cairo',sans-serif;
}
```
